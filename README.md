# 2D Football Arena v2

## O que mudou

- Menu para escolher a camisa de cada jogador.
- Modo 1 PLAYER contra CPU.
- Modo 2 PLAYERS no mesmo teclado.
- P1: WASD + Espaço.
- P2: Setas + P.
- P1 usa Espaço como tecla de chute; P2 usa P.
- Segurar a tecla de chute carrega a força.
- Quanto mais tempo segurando, mais forte o chute.
- Encostar no jogador NÃO empurra a bola.
- O contato jogador-bola apenas impede que a bola atravesse o jogador.
- O chute é a ação que altera diretamente a velocidade da bola.

## Controles

### 1 Player
P1: W A S D
Chute: Espaço
Menu / Pausa: 0
Menu: Esc

### 2 Players
P1: W A S D + E
P2: Setas + P
Menu / Pausa: 0
Menu: Esc

## Rodar com Java

Java 17+:

```bash
javac Main.java
java Main
```

Depois abra:

http://localhost:8080

Também é possível abrir `index.html` diretamente.
